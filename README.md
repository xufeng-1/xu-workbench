# xu的工作台

浅紫薰衣草主题的个人专属工作台 PWA，支持安卓 / 鸿蒙 / 苹果三端「添加到主屏幕」使用。
数据由 GitHub Actions 每天 07:20（北京时间）自动更新，无需任何人工操作。

## 目录结构
- `docs/` —— PWA 应用本体 + 数据（GitHub Pages 从该目录发布）
- `scraper/` —— 每日自动更新脚本（在 GitHub 免费服务器上运行）
- `.github/workflows/daily.yml` —— 每日定时任务（北京时间 07:20）
- `tools/make_icons.ps1` —— App 图标生成脚本

## 使用方式（手机端安装）
1. 打开部署后的网址（例如 `https://<你的用户名>.github.io/xu-workbench/`）
2. 安卓/鸿蒙：浏览器菜单 →「添加到主屏幕」；苹果：分享 →「添加到主屏幕」
3. 之后像普通 App 一样点图标打开，全屏使用，离线也能看

## 每日更新机制
- 定时任务每天抓取抖音热榜 → 生成当日：健身视频、AI漫剧、爆款脚本、数据分析视频、川菜菜谱
- 英语词库不足时自动从公共词库扩充（六级/雅思/求职）
- 新概念每周生成一篇新原创课文；口语场景池每周轮换
- 数据分析历史视频全部保留，便于复习
- 若当天抖音接口被风控，自动降级为话题池轮换（内容不重样、链接仍可打开抖音）

## 进阶：提高抖音抓取成功率（可选）
在仓库 Settings → Secrets and variables → Actions 添加 Secret：`DOUYIN_COOKIE`
值为你浏览器登录抖音后复制的一段 Cookie，脚本会自动尝试用真实会话抓取视频详情。
不配置也能正常运行（自动降级），只是视频以话题链接形式呈现。

## 本地开发
```powershell
# 手动跑一次每日更新（需要在有 Python 的机器上）
python scraper/daily.py .
```
